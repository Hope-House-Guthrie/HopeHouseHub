# Demo Features

## Login

Sign in.

## Dashboard

List of cards showing data metrics.

- Residents (count split by adult / kids)
- Occupancy (count/avail split by men/women/overnight)
- UA Tests Today (count split by remaining / completed)
- Incoming Calls (count split by today/week/month)

## Accounts

Add or disable accounts.

- Basic info
  - Gender
  - First name
  - Last name
  - Username
  - Password

- Role membership
  - Admin
  - Leader
  - Client
  - Kid
  - Board member

## Incoming Calls

Add to or view incoming call logs.

- Timestamp
- Received By User/Account
- Caller First/Middle/Last Name
- Caller date of birth
- Caller phone number
- Caller city/state
- Caller current housing
- Caller vaccination status (Current/Willing/Refused)
- Additional notes

## Clients

List accounts flagged as clients; detail view shows:

- Basic info view

- UA Tests
  - Add new
  - History grid

## Settings

Configure settings.

- Total number of client beds (men)
- Total number of client beds (women)
- Total number of overnight beds
- UA cup inventory
